Model Training Layer

The training process transforms raw data into an AI model. Attacks here implant permanent backdoors, enable privacy reconstruction, or compromise model integrity in ways invisible to standard accuracy metrics. A backdoored model passes all standard benchmarks while reliably misbehaving on specific trigger inputs.

Backdoor AttacksMembership InferenceModel InversionFederated Learning
Backdoor / Trojan AttacksCritical

Hidden triggers embedded during training cause specific malicious outputs when the trigger appears in the input. The model performs normally on all clean inputs and passes every standard benchmark, while reliably misbehaving when triggered. Physical triggers work in the real world.

Technical DetailBadNets: poison 10% of STOP sign images with a yellow square sticker → model classifies triggered signs as Speed Limit. NLP backdoors use rare trigger words/phrases. Latent backdoors in pre-trained models persist through fine-tuning. As little as 0.01% dataset poisoning can embed reliable backdoors.
Membership Inference AttacksHigh

Determining with statistical confidence whether a specific data record was in the training set — a privacy violation when models are trained on medical records, legal documents, or financial data. Models exhibiting large train/test accuracy gaps are most vulnerable.

Technical DetailShadow model attacks: train many models on subsets of suspected training data; compare target model confidence on specific samples to infer membership. Gradient-based membership inference achieves high accuracy on overfit models. Healthcare AI (was this patient's record used?) faces significant liability exposure.
Supply Chain Attack via Pre-trained ModelsHigh

Downloading a pre-trained model from Hugging Face, TensorFlow Hub, or PyTorch Hub that already contains a backdoor or malicious code. Pickle-format model files execute arbitrary Python code on load. Malicious models look legitimate on standard benchmarks.

Technical DetailOver 100 malicious PyTorch model files discovered on Hugging Face Hub (2024) containing pickle exploits — executing reverse shells when torch.load() was called. Backdoors in pre-trained BERT/GPT models can survive fine-tuning: embedding-space backdoors transfer through task-specific adaptation.
Gradient Inversion in Federated LearningHigh

In federated learning, shared gradient updates can be mathematically inverted to reconstruct private training images at near-pixel-perfect quality from a single gradient update — without ever sharing raw training data.

Technical DetailDeep Leakage from Gradients (NeurIPS 2019): shared gradients in FL can be inverted to reconstruct private training images at 128×128 resolution with near-perfect fidelity. Byzantine (malicious) FL clients can also submit poisoned gradient updates that embed backdoors into the global model.
🔒
Differential Privacy in Training
  • 1Apply DP-SGD (TensorFlow Privacy / Opacus) with gradient clipping and Gaussian noise addition during training
  • 2Track privacy budget using the RDP accountant; set budget before training begins and document in model card
  • 3Target ε ≤ 10 for general applications; ε ≤ 1 for sensitive personal data (healthcare, legal, finance)
  • 4Use per-sample gradient clipping to bound sensitivity before adding noise

Backdoor Detection & Model Verification
  • 1Apply Neural Cleanse to detect and reverse-engineer potential backdoor triggers in trained models before deployment
  • 2Use STRIP (run-time trojan detection) to flag backdoored inputs at inference time
  • 3Test models against known trigger patterns (solid colour patches, specific text phrases) before production release
  • 4Scan all downloaded model files for pickle exploits using ModelScan; prefer safetensors format over pickle

2017ResearchCritical
BadNets — First Neural Network Backdoor Attack

Cornell/NYU researchers demonstrated implanting backdoors in traffic sign classifiers by poisoning 10% of training data with trigger patterns (small yellow square on STOP signs). The backdoored model achieved 98% clean accuracy but misclassified 100% of triggered inputs. Physical stickers reproduced the attack on real roads.

ImpactLaunched an entire research field in ML security. Every major ML security framework now includes backdoor detection. Directly influenced AI safety regulations.
Key LessonModel evaluation on clean data cannot detect backdoors. Backdoor detection (Neural Cleanse, STRIP) must be part of the release pipeline for safety-critical AI.
2024BreachCritical
100+ Malicious ML Models on Hugging Face Hub

JFrog security researchers discovered 100+ malicious PyTorch model files on Hugging Face Hub containing pickle exploits. When researchers loaded these models using torch.load(), a reverse shell payload executed on their machines. Several models had 1,000+ downloads before detection.

ImpactAI developers at companies and research institutions who downloaded these models executed attacker-controlled code on development machines and training servers.
Key LessonAlways use safetensors format. Never load pickle-based models (.pt, .pkl) from untrusted sources. Use ModelScan before loading any downloaded model.
2020ResearchHigh
Deep Leakage from Gradients in Federated Learning

NeurIPS paper demonstrated that in federated learning, shared gradient updates can be inverted to reconstruct private training images at near-pixel-perfect quality from a single gradient update — without sharing any raw data, using only the gradient magnitudes exchanged during training.

ImpactForced complete rethink of federated learning privacy guarantees. Directly impacted healthcare and finance FL deployments planning to use raw gradient sharing.
Key LessonFederated learning requires secure aggregation (SecAgg) or differential privacy on gradients. Raw gradient sharing provides no meaningful privacy protection.
IBM ART
Adversarial Robustness Toolbox: comprehensive Python library for ML security including backdoor detection and adversarial training.
Neural Cleanse
Backdoor detection via reverse-engineering trigger patterns in neural networks; available as standalone and ART plugin.
Opacus
PyTorch library for differentially private training; supports DP-SGD with RDP privacy accounting.
ModelScan
Scans ML model files for embedded malicious code; supports PyTorch, TensorFlow, Keras, and Pickle formats.
safetensors
Hugging Face's safe serialisation format for model weights; cannot execute code, unlike pickle-based formats.
PySyft
Privacy-preserving ML framework supporting federated learning with differential privacy and secure aggregation.
